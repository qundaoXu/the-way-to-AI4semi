# 研究锚点说明

研究锚点是来自真实研究场景的问题，用来回答“为什么要学这一章”。每个锚点给出问题描述、需要的知识链条和推荐的学习顺序。章节与锚点的对应关系以 `curriculum.yaml` 为准，汇总见[课程总目录](../CURRICULUM.md)。

**使用规则。** 锚点只作为动机与案例背景。仓库中的示例一律使用公开数据或合成玩具体系，不放入未发表的数据、结果或手稿内容。本页的描述也只停留在一般性问题的层面。

下文的“知识链条”按依赖顺序排列，箭头左边是右边的前置。链条中的章节目前大多尚未建设，按即时建设原则在学到时创建。

## A1 力、应力与能量守恒

**问题。** 力与应力如何由能量模型通过自动微分得到？为什么有些势在 NVE 模拟中能量不守恒？

**展开。** 一个势只要把力定义为能量的负梯度，力场就是保守的。能量漂移通常来自别处：模型直接预测力而不是对能量求导；截断处能量或其导数不连续；积分器不是辛的或步长过大；邻居表更新不及时；单精度累积误差。要定位原因，需要同时理解自动微分得到的到底是什么、积分器保证的又是什么。

**知识链条。** M02.2 矩阵微积分 → M05.2 自动微分（力是能量的负梯度，应力是能量对应变的导数，高阶导数与 `create_graph`）；M02.6 数值方法（Verlet 与辛积分的能量守恒性质）→ M07.3 机器学习势的训练与验证。

**推荐顺序。** M02.2 → M02.6 中的 ODE 积分器部分 → M05.2 → M07.3。

**可检验的产出。** 用 autograd 实现 Lennard-Jones 势的力与应力，与有限差分对比，并在 NVE 中验证能量守恒（Module 05 毕业标准）。

## A2 主动学习为什么会失效

**问题。** 主动学习迭代多轮后，模型在目标构型上没有改进。可能的原因有哪些，怎样区分？

**展开。** 三类常见原因。探索器采到的构型分布与真正关心的构型分布不匹配，新增数据落在无关区域。不确定性估计不准，高不确定性并不对应高误差，筛选等于随机。不同批次的标注设置不一致，新旧数据之间存在系统偏差，模型在拟合标注差异。三者的诊断方法不同，分别对应分布偏移、校准评价和数据一致性检查。

**知识链条。** M03.4 数据划分、泄漏与分布偏移 → M06.5 不确定性量化、主动学习与贝叶斯优化（校准评价、采集函数、失败模式）→ M07.3 训练集构建与 DFT 设置一致性 → M07.4 通用势作为探索器时的分布问题。

**推荐顺序。** M03.4 → M04.7 中的校准部分 → M06.5 → M07.3 → M07.4。

**可检验的产出。** 在一个回归任务上比较三种 UQ 方法的校准表现，并写出主动学习失败模式的分析笔记（Module 06 毕业标准）。

## A3 低 RMSE 不等于可用的势

**问题。** 为什么能量和力的误差指标很低的势，在实际模拟中仍可能不可用？怎样设计分层的评价体系？

**展开。** 误差指标是在与训练集同分布的测试集上算的，它是一个代理指标。实际使用关心的是：MD 能否长时间稳定运行，结构、动力学和热力学性质是否正确，下游的电子结构是否合理。代理指标与最终目标不一致，是 ML 研究方法论里的一般性问题，MLIP 是它的一个具体实例。

**知识链条。** M04.7 模型评价与解释 → M04.8 ML 研究方法论（代理指标、基线、消融、统计比较）→ M07.3 分层验证体系（误差指标 → MD 稳定性 → 结构、动力学与热力学性质 → 电子结构）。M04.2 线性模型是远期铺垫：它是少数能把“拟合误差小”和“参数被数据良好约束”分开看清楚的场合。

**推荐顺序。** M04.7 → M04.8 → M07.1 → M07.3。

**可检验的产出。** 一篇 1–2 页的方法论短文，说明为什么误差指标不足以评价 MLIP，并提出分层评价思路（Module 04 毕业标准）；在 rMD17 上给出自写 MLIP 的分层验证报告（Module 07 毕业标准）。

## A4 大尺度无序体系的电子结构

**问题。** 大尺度无序体系没有明显带隙，存在带尾和局域态。怎样计算和刻画它的电子结构？涉及的大规模稀疏矩阵该用什么数值方法？

**展开。** 体系一大，稠密对角化的 $O(N^3)$ 代价就不可行。可行的路线是利用哈密顿量的稀疏性：只求部分本征态的迭代方法（Lanczos 类），或者完全不求本征态、直接估计态密度的方法（核多项式方法 KPM）。刻画无序体系还需要局域化指标，如逆参与率（IPR）、迁移率边、Urbach 带尾。

**知识链条。** M02.1 线性代数（特征分解、条件数）→ M02.6 数值方法（稀疏矩阵、Lanczos）→ M07.5 电子结构机器学习（ML 哈密顿量、KPM、局域化指标）。Module 01 提供支撑：M01.2 的邻居搜索和 M01.5 的高性能 Python 解决大体系数据处理的性能问题。

**推荐顺序。** M02.1 → M02.6 → M06.3（ML 哈密顿量的等变性设计需要）→ M07.5。

**可检验的产出。** 实现共轭梯度法与 Lanczos 算法并与 SciPy 对比（Module 02 毕业标准）；实现紧束缚模型，用 KPM 与精确对角化计算 DOS，并计算 IPR（Module 07 毕业标准）。

## A5 老化轨迹的时间序列分析

**问题。** 老化过程跨越多个时间量级，数据常按对数时间采样。怎样估计趋势、识别漂移和变化点？

**展开。** 对数时间采样下，样本在时间轴上极不均匀，早期密、晚期疏。直接套用均匀采样的方法（滑动窗口、自相关、标准变化点检测）会得到被采样方式扭曲的结果。需要弄清每种方法对采样的假设，以及在对数时间轴上重新表述问题意味着什么。

**知识链条。** M02.4 数理统计 → M03.5 时间序列（平稳性、趋势、变化点检测、非均匀与对数时间采样）→ M08.5 可靠性与优化（退化趋势预测、生存分析）。

**推荐顺序。** M03.2 → M03.5；选择 Path C 时继续 M08.5。

**可检验的产出。** 对一条合成的老化型时间序列，比较线性与对数时间采样下的趋势估计与变化点检测效果（Module 03 毕业标准）。

## A6 晶体生成与电荷密度预测

**问题。** 扩散模型怎样处理晶体的周期性与对称性？生成结果的质量怎样评价？

**展开。** 晶体不是普通的欧氏空间数据：分数坐标生活在环面上，晶格参数有自己的约束，整体还要满足空间群对称性。生成模型必须在这些几何结构上定义加噪和去噪过程。评价同样不平凡，有效性、稳定性、新颖性、多样性衡量的是不同的事情。电荷密度预测面对同样的对称性要求，输出是等变的标量场。

**知识链条。** M02.7 群论与表示论（对称群、不可约表示、空间群）与 M02.8 随机过程与采样（Langevin 动力学、SDE）→ M06.3 等变网络 与 M06.4 生成模型（扩散模型、Flow Matching）→ M07.5 电荷密度预测、M07.6 晶体与材料生成模型。

**推荐顺序。** M02.3 → M02.8 → M06.4（先在玩具分布上理解扩散）；M02.7 → M06.3；两条线汇合到 M07.6。

**可检验的产出。** 在二维双势阱上实现 Langevin 采样（Module 02）；在二维玩具分布上实现 DDPM 与 Flow Matching（Module 06）；在简化设置下复现一个晶体生成方法的核心训练步骤并实现基本评价指标（Module 07）。

## A7 用 PCM 电导态表示神经网络权重

**问题。** 用相变存储器件的电导态表示神经网络权重时，量化、噪声与电导漂移怎样影响模型？怎样补偿？

**展开。** 模拟存内计算把矩阵–向量乘法交给交叉阵列的物理过程完成。代价是权重不再精确：电导态数目有限（量化），写入和读出有噪声，电导随时间漂移。这把器件物理直接变成了对训练算法的约束，对应的方法是量化感知和噪声感知训练。

**知识链条。** M05.4 训练与优化技巧 → M12.5 AI 硬件与模拟存内计算（量化、噪声感知训练、漂移补偿）；M01.4 计算机系统基础 → M11.1 并行计算基础与性能分析（存储层次与带宽瓶颈，说明存内计算要解决的问题）。

**推荐顺序。** M05.1–M05.4 → M11.1 → M12.5。对应 [Path D](../learning-paths/path-d-hardware-for-ai.md)。

**可检验的产出。** 在 M12.5 建设时确定。

## A8 跨尺度传递与不确定性传播

**问题。** 怎样把机器学习分子动力学得到的热物性传递到连续介质电热仿真，再到器件代理模型？各层的不确定性怎样向下游传播？

**展开。** 多尺度建模的每一层都把上一层的输出当作输入参数。每次传递都引入误差：原子尺度的统计误差和模型误差，连续介质模型的离散误差，代理模型的拟合误差。要回答“器件层面的预测有多可信”，就得让不确定性沿着这条链传下去，而不是只在某一层报告误差。

**知识链条。** M02.6 数值方法（PDE 离散）→ M07.8 神经算子（PDE 代理模型及其评价）→ M07.9 多尺度、可微分模拟与逆向设计（参数传递、多保真学习、不确定性传播）→ M07.10 器件仿真中的 AI（电热耦合代理模型、PCM 器件建模）。M06.5 提供不确定性量化的基础。

**推荐顺序。** M02.6 → M07.7 → M07.8 → M06.5 → M07.9 → M07.10。

**可检验的产出。** 用 FNO 和 PINN 求解同一个二维热传导问题，与有限差分参考解比较精度和计算成本（Module 07 毕业标准）；Project 05。
