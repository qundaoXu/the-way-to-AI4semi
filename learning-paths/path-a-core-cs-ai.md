# Path A：Core CS / AI

## 目标

系统补齐非科班背景的通用 CS/AI 知识：工程基本功、数学基础、统计学习、深度学习和可复现的项目组织。它是 [Path B](path-b-ai-for-science.md) 和 [Path C](path-c-semiconductor-industrial-ai.md) 的公共底座。

## 前置

Python 科研脚本经验和 Linux 使用经验。不要求任何模块作为前置。标为 `FT` 的章节如果已经熟悉，只浏览精要并运行实例 notebook。

## 章节顺序

数学与编程穿插进行，不要求修完全部数学再开始机器学习。章节内容见[课程总目录](../CURRICULUM.md)。

| 步骤 | 章节 | 说明 |
|---|---|---|
| 1 | M01.1、M01.3、M01.5、M01.2 | 工程基本功。M01.1、M01.3 是 FT 候选；M01.4 为 P1，可延后 |
| 2 | M02.1 → M04.1 → M02.2 → M04.2 → M02.3 → M02.4 → M04.3 → M02.5 | 数学与统计学习交替：每学一块数学，紧接着用到它的 ML 章节 |
| 3 | M03.1 – M03.4 | 数据处理与划分。M03.4（泄漏）是研究者必修；M03.5、M03.6 为 P1 |
| 4 | M04.4、M04.5、M04.7、M04.8 | Module 04 其余的 P0 章节；M04.6 为 P1 |
| 5 | M02.6 | 数值方法，Module 05 中自动微分与训练稳定性的前置 |
| 6 | M05.1 – M05.4 | 深度学习核心；M05.5 为 P1，M05.6 为 P2 |
| 7 | M06.1、M06.2 | Transformer 与图神经网络基础 |
| 8 | M09.1、M09.2 | 工程化与可复现性 |

试点章节 M04.2 已建设，它的先修 M02.1、M02.2、M02.4 尚未建设；从 M04.2 开始时，按讲义第 2、3 节的指引补充所需的数学。

## 阶段性检查点

| 检查点 | 完成标志 |
|---|---|
| 工程基本功 | 一个旧科研脚本重构为可安装的包；cell list 邻居搜索与 ASE 一致 |
| 线性模型与核方法 | 线性回归、逻辑回归、高斯过程回归的从零实现通过测试 |
| 统计学习 | 决策树、K-means 通过测试；Matbench 比较报告含基线、消融和多种子统计 |
| 深度学习 | 自写 autograd 引擎训练小 MLP；Lennard-Jones 力与应力通过梯度检验 |
| 现代架构 | mini-Transformer 训练字符级语言模型；不变 GNN 通过对称性测试 |

各模块完整的毕业标准见模块 README。
