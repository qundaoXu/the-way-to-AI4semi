# Path B：AI for Science（主路径）

## 目标

建立从原子模拟、电子结构到器件代理模型的科研技术体系：把已经在用的工具（MLIP、ML 哈密顿量、扩散模型）从“会用”提升到“理解原理、能修改、能诊断、能独立实现简化版本”。实践背景以非晶相变材料、电子结构和器件电热耦合为主，示例只使用公开数据或合成体系。

## 前置

[Path A](path-a-core-cs-ai.md) 的内容。两条路径并行推进，不必先完成 Path A：下表每一步列出了它实际依赖的 Path A 章节。

默认每周 8–10 小时。这是诊断之前的默认排期；Phase 1b 的诊断完成后，由个人化的 `ROADMAP.md` 取代。

## 阶段性检查点

| 检查点 | 完成标志 |
|---|---|
| 数值与对称性基础 | 共轭梯度与 Lanczos 与 SciPy 对齐；实球谐函数通过随机旋转检验 |
| 等变网络 | 用 e3nn 构建等变消息传递层并数值验证等变性 |
| MLIP | 在 rMD17 上训练自写的小型 MLIP，给出分层验证报告 |
