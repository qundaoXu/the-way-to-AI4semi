**各章范围**

- **M12.1 因果机器学习**：因果图与结构因果模型；因果效应估计；分布偏移下的因果视角。因果推断的主要归属章节。
- **M12.2 强化学习**：MDP；基于价值的方法；策略梯度；离线强化学习；实验与工艺决策优化。
- **M12.3 概率机器学习**：贝叶斯神经网络；变分推断；概率编程；与 M06.5 的关系。
- **M12.4 机器学习系统**：编译与算子优化基础；高性能算法实现；ML 系统设计。
- **M12.5 AI 硬件与模拟存内计算**：神经网络量化；噪声感知训练；PCM 交叉阵列的存内计算原理；电导漂移对权重的影响与补偿；硬件感知训练工具（如 IBM aihwkit）。本章连接“器件物理”与“AI 系统”。
